# 测试候选版使用说明

1. 保留旧 export21，先安装 X2-shared-download.apk，再安装 51-shared-download.apk。
2. 在新版 X2 的下载设置中选择保存目录，允许所需目录访问，并按需设置后台运行和并发数。
3. 若使用旧视频目录，可点击“导入此目录已有视频（保留旧文件）”。旧私有队列、原源指纹和旧设置不包含在文件导入中。
4. 测试两个按钮是否并排、可拖动且重启后保留位置。用两条全新视频分别下载，退出客户端后检查后台保存，再检查共同管理页、重复提示和本地续播。

这是未经运行验收的候选版，不保证上述功能已正常工作。两个新版有独立安装身份，不覆盖旧版。仅删除记录会保留视频；若明确选择删除 MP4，同目录中其他 App 使用的那个物理文件也会被删除。

两份 APK 使用同一把新签名密钥。原签名私钥未恢复。本次源码是重建，并非历史共享版源码恢复。未附带任何模拟测试入口 APK。
