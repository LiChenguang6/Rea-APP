# Rea-APP

Android 跨 App 共享下载重建项目。当前提供用户自行测试的候选 APK，尚未完成端到端功能验收。

文件位于 [下载文件夹](下载文件夹/)。请先安装 X2 共享下载版，再安装 51盒共享下载版。两者使用独立包名，可以保留旧版；不要卸载旧版或清除旧数据。

## 当前边界

- 两个新版 APK 需要一起安装；后续兼容客户端可沿用共享协议和签名，只安装新客户端。
- 新版 X2 持有唯一的新共享队列、目录授权、设置、管理页和播放进度。旧 export21 保留独立运行，旧队列不会自动互通。
- 新版设置中选择旧保存目录，再点击“导入此目录已有视频（保留旧文件）”。这项实现尚待运行验收。
- 旧 MP4 不包含原源指纹，不能保证导入后首次提交旧视频源时立即拦截。
- 原类、原生库、assets 和 APK 签名校验通过；云端模拟器系统服务反复失败，未验证拖动、两次全新下载、后台保存、共享历史、去重或续播。
- 保留原视频源配置；真实源播放未在云端验证。本任务不涉及账户或视频权限绕过。

下载校验见 [SHA256SUMS.txt](下载文件夹/SHA256SUMS.txt)。源码备份不包含 APK 输入包、私钥或密码；新签名材料单独私密保存，绝不能提交到 Git。

## 环境恢复备份

完整工作区的加密 7z 分卷位于 [环境备份](环境备份/)。只使用 manifest.json 标记 complete 的快照。密码不上传公开仓库，由用户通过私密聊天另存。以后每次生成新产物或重要源码变更，都须制作新快照；规则见 AGENTS.md。
