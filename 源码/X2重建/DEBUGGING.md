## 原播放器组件合成素材测试

单独创建底包原 FlutterEngine，关闭自动插件注册，不执行原 App 的 Dart 主入口。注册未替换的 BetterPlayer 插件，以本地 HTTP 服务提供非色情的合成 MP4，调用原插件的 create / setDataSource / play / pause / dispose。

最终测试通过：数据源按实际播放生命周期选择；预加载不能替换当前源；带 licenseUrl 的 DRM 源不进入下载捕获；原 BetterPlayer 创建纹理播放器；原播放方法触发新桥接，URL 与请求头保持一致；ExoPlayer 进度推进且无播放错误；暂停后的当前源在短时间内仍可供下载界面使用；释放后拒绝旧源。

首次组件检查仅等待1.6秒，未等到解码准备，断言失败。重跑改为有界等待实际进度或错误，观察到约7秒后进度221ms且错误为空，通过断言。该改动只作用于测试等待，不改变生产 APK，也不是性能验收。

这些结果验证播放器组件和下载捕获适配，不覆盖真实首页、登录、授权与源站观看。需要手机实测后才能关闭黑屏问题。完整队列、后台保存和拖动在本轮未做新一轮端到端验证。
